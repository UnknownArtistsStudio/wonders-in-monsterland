# Wonders in Monsterland

An interactive music-window prototype with three vertically scrolling scenes. Each film loops silently while its supplied track plays through a low-pass filter. Moving the white-dot pointer over the flashing window opens the filter to reveal the full track. The active track changes as each scene enters the viewport.

## GitHub Pages

Upload the contents of `dist` to the root of a GitHub Pages repository, or publish `dist` from a Pages deployment workflow. All media paths are relative, so the site works at either a custom domain or a repository subpath.

Audio begins after the visitor selects “Enter Monsterland”, as required by modern browsers. On touch devices, tap the window to open or close the music.
